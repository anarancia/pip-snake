PiP Snake

Un petit snake dans une fenêtre toujours au premier plan. Tu continues à lire et scroller les autres onglets pendant qu'il tourne.

Ton navigateur n'a pas le Document Picture-in-Picture (Chrome/Edge 116+). On passe en mode vidéo : les flèches marchent tant que cet onglet reste actif.

Comment ça marche

  1. Clic sur le bouton pour lancer.
  2. Clic sur la fenêtre pour jouer (flèches, WASD ou ZQSD ; Espace = pause ; Entrée = rejouer).
  3. Clic ailleurs = pause.
